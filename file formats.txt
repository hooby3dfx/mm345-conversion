MM3 sprite format differences:
- CMD 0: same as MM4 CMD 0 (len + 1 bytes are palette indexes)
- CMD 1: also same as MM4 CMD 0 (len + 1 bytes are palette indexes)
- CMD 2: NOT SURE... STOP?
- CMD 3: NOT SURE (stream copy?)
- CMD 4: same as MM4 CMD 5 (skip len + 1 pixels)
- CMD 5: same as MM4 CMD 5 but skip len + 33 pixels (like MM4 CMD 1)
- CMD 6: same as MM4 CMD 2 (draw len + 3 times)
- CMD 7: NOT SURE; same as MM4 pattern?



EXE/DAT File Contents:
There are strings and other bits inside both XEEN.EXE and XEEN.DAT.
XEEN.EXE is a DOS exe and XEEN.DAT seems like a dll.
Both are compressed with "PKLITE" but can be decompressed with UNP 4.11, and then viewed with a hex editor and/or IDA 5.0.

The background color for UI menus is in XEEN.DAT at uncompressed offset 0x41A7C as 0x9999, as the palette index for MM4 is 0x99 (153). In the MM3 palette this is a dark blue; a better tan color for MM3 palette is 0xE9E9.
